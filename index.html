家具資料與擺放尺寸

圖片依個別底座對齊占地中心；較小底座置中，保留屋頂等立體高度；四款 8×8 雕像採相同顯示高度。翠瓦依各張原圖的底座接點對齊。圖片的自由縮放、水平與垂直偏移、角度及圖層，請使用「素材編輯器」。此處調整家具的擺放資料。圍欄保留完整範圍框，碰撞沿中線只有半寬，允許端點對端點接合；勾選「家具占地」可查看橘色碰撞範圍。翠瓦直牆沿占地中線接至兩端邊界，專用轉角也接至兩側邊界；翠瓦牆彼此相鄰擺放，範圍不能部分重疊。左右翻面會翻轉圖片與圍欄接向，占地長寬不變。正方形只保留左右翻面；長方形另有「轉向・交換長寬」，會交換寬深並翻面。素材沒有其他視角。舒適值留空表示尚未確認。

素材資料夾怎麼放？

這是分離素材版。index.html 讀取旁邊「家具素材」資料夾，兩者需一起上傳 GitHub Pages。本機使用「啟動工坊.bat」，不必連網。修改 PNG 或 manifest 後，執行「重新打包.bat」（Python 3），再重新整理工坊網址。

加入透明 PNG，命名如「木桌__4x4.png」，再按匯入資料夾。也可用 manifest.json 指定名稱、占地與圖片倍率。同 ID 不會重複加入。

輕量配置記錄擺放與調整值，內建圖片沿用網站素材；只有自訂圖片隨檔保存。可把「AI 設計資料」網址與配置一起交給 AI。離開前記得儲存配置。

已收錄 192 件、22 個分類。家具、翠瓦牆及地板都取用資料夾中的原 PNG；地板保留原圖紋理與外緣，相鄰同款自動拼接。圍欄端點可對接，不能接到牆身；可沿完全貼齊建築的共同邊界放置。拿地板時自動切換「只選地板」，Esc 或取消選取切回「只選家具」。勾選「隱藏建築圖片」可透視查看地板，建築占地框仍保留。草地是清除地板工具，會露出原本草地。新地板可直接替換舊地板，但不會移除星空建築下的星空窗或船底水池。木星磚是普通地板，可放一般家具，不能放星空建築；其他異星迷航家具需先鋪滿星空窗；大亨藏品船隻需先鋪滿水池。

家具資料與實際占地

以下獨立按鈕會修改實際資料；占地變更會檢查場上碰撞。請用 manifest.json 或配置檔保存。

匯出完整素材設定

匯出 manifest.json → 覆蓋「家具素材」內同名檔 → 重新打包 → 重新整理工坊網址。包含全部素材資料與調整值；在編輯器替換的 PNG 也會帶入打包。場上擺放另用頂部「儲存配置」。

用本機網址開啟家園工坊

圖片現在放在旁邊的素材資料夾。請雙擊「啟動工坊.bat」，讓圖片編輯及匯出功能正常運作；使用期間保留啟動視窗。

其他系統可在此資料夾執行：

python3 serve.py

需要 Python 3，使用時不必連網。放到 GitHub Pages 後，直接開啟網站網址即可。
